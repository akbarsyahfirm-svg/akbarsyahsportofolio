# Akbarsyah Firman Prasetyo — Portfolio

Updated website with your supplied profile photo.

## Upload to your existing GitHub repository
1. Open your repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `profile-photo.jpg` from this folder.
4. Commit changes to `main`.
5. Wait a few minutes, then refresh your GitHub Pages site.

Keep the three files together in the repository root. Review the content before publishing and do not upload confidential employer documents or customer/site data.
