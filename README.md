## Update your existing GitHub Pages repository
1. Open your repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `profile-photo.jpg` directly into the repository root.
4. Commit changes to the `main` branch.
5. Wait a few minutes, then refresh the website using Ctrl+F5.

The photo itself is unchanged; only the website's color palette has been updated.
