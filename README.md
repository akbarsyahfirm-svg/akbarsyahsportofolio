# Akbarsyah Firman Prasetyo — Portfolio

Updated portfolio with profile photo and clickable certificate links.

## Update the existing GitHub Pages repository
1. Open your repository.
2. Choose **Add file → Upload files**.
3. Upload these three files directly into the repository root: `index.html`, `style.css`, and `profile-photo.jpg`.
4. Commit changes to the `main` branch.
5. Wait a few minutes, then refresh your website with Ctrl+F5.

The certificate buttons open the Google Drive documents in a new tab. Check that each Drive file is shared so recruiters with the link can view it.

Do not upload confidential employer documents, customer data, or identifiable site records.
